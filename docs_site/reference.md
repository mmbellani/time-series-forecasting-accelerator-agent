# Library Reference

Helper functions are grouped by area:

| Module | Purpose |
|---|---|
| Plotting | Visualise series, forecasts and diagnostics |
| Profiling | Intermittency indicators and series profiles |
| Regressors | External / exogenous variables |
| Scoring | Generate and evaluate forecasts |
| KPI | Forecast accuracy metrics |
| Utils | Shared helpers |

!!! tip
    For signatures, add `mkdocstrings` later to generate this page automatically from docstrings.
