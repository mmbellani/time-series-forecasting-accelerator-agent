## The forecaster's toolbox

1. **Know your series** — profile before you model.
2. **Group, don't multiply** — cluster series and train one model per group.
3. **Let features carry the signal** — lags, rolling stats, calendar effects.
4. **Validate like you'll deploy** — time-based backtesting, never random splits.
